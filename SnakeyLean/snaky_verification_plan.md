# Snaky Hexomino Strategy Verification Plan

The current `SnakeyProof.lean` file fails to compile because it attempts to use the `decide` tactic on `winning_strategy`, which quantifies over all possible Breaker moves (`∀ b : Grid`). Since `Grid = Int × Int` is infinite, `decide` cannot evaluate it.

However, the strategy tree generated by FunSearch actually only branches on a finite number of specific Breaker moves (via `if b = ... then ... else ...`). We can exploit this to create a strictly finite evaluation algorithm in Lean that guarantees a win against *all* infinite possible Breaker moves.

## 1. Redefining the `StrategyTree`

We need to change `StrategyTree` in `SnakeyStrategy.lean` so the explicit cases are visible to Lean's evaluator, rather than hidden inside an opaque function `Grid → StrategyTree`.

```lean
inductive StrategyTree
| win : StrategyTree
| move (m : Grid) (cases : List (Grid × StrategyTree)) (default : StrategyTree) : StrategyTree
```

## 2. The Finite Verification Algorithm

The key insight is: **A Breaker move `b` only affects the game if it blocks a future Maker move.**
If the Breaker plays a move `b` that falls into the `default` branch, that move `b` is harmless *as long as the Maker never tries to play `b` in that default branch*.

We can write a Lean function `verify_tree` that recursively checks the tree and returns the set of all Maker moves it intends to play (or `none` if the tree is invalid):

```lean
def verify_tree (target : List Grid) (tree : StrategyTree) (maker_cells breaker_cells : List Grid) : Option (List Grid) :=
  match tree with
  | .win => 
      if checkWin maker_cells target then some [] else none
  | .move m cases default =>
      if m ∈ maker_cells ∨ m ∈ breaker_cells then none
      else
        let next_m := m :: maker_cells
        
        -- 1. Verify the default branch (assuming Breaker plays a harmless move)
        match verify_tree target default next_m breaker_cells with
        | none => none
        | some default_maker_moves =>
            -- 2. CRITICAL CHECK: Every future Maker move in the default branch 
            -- MUST be explicitly guarded in `cases`! If not, the Breaker could play 
            -- it right now, fall into the default branch, and block the Maker later.
            let unguarded := default_maker_moves.any (fun d_m => 
              d_m ∉ next_m ∧ ¬cases.any (fun (b, _) => b == d_m)
            )
            if unguarded then none
            else
              -- 3. Verify all explicit cases
              let cases_ok := cases.foldl (fun acc (b, subtree) =>
                match acc with
                | none => none
                | some moves =>
                    if b ∈ next_m ∨ b == m then some moves -- Invalid Breaker move, skip
                    else match verify_tree target subtree next_m (b :: breaker_cells) with
                         | none => none
                         | some case_moves => some (moves ++ case_moves)
              ) (some [])
              
              match cases_ok with
              | none => none
              | some all_case_moves => some (m :: default_maker_moves ++ all_case_moves)
```

### Why this works:
1. It validates all explicit Breaker moves via the `cases` branches.
2. It validates the `default` branch assuming the Breaker move doesn't interfere.
3. It strictly ensures that the Breaker *cannot* interfere in the `default` branch by asserting that all of Maker's planned default moves were explicitly branched upon in `cases`. If Breaker plays any other cell, it's guaranteed to be a cell Maker doesn't care about!
