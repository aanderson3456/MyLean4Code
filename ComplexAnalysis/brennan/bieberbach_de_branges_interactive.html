De Branges's Theorem: The Bieberbach Conjecture ($|a_n| \le n$) via Loewner Chains

In 1916, Ludwig Bieberbach proved $|a_2| \le 2$ for every normalized univalent function $f(z) = z + \sum_{n=2}^\infty a_n z^n \in \mathcal{S}$ on the unit disk $\mathbb{D}$ and conjectured that $|a_n| \le n$ for all $n \ge 2$ (with equality for the Koebe function $K(z) = \frac{z}{(1-z)^2} = \sum_{n=1}^\infty n z^n$). In 1984, Louis de Branges proved the full conjecture by discovering a miraculous sum-of-squares dissipation identity along Loewner's PDE. This interactive paper presents the complete 4-stage proof chain—backed by 0-sorry, 0-axiom Lean 4 proofs in brennan/DeBrangesBieberbach.lean and brennan/Koebe.lean.

How All Pieces Fit Together: The 4-Stage De Branges–Milin–Bieberbach Pipeline

Stage I • Loewner + Parallelogram
De Branges's Algebraic Miracle
Along Loewner's PDE, $\Phi_n'(t)$ telescopes via $\sigma_k - \sigma_{k+1} = -\frac{\sigma_k'}{k} - \frac{\sigma_{k+1}'}{k+1}$ into $\sum_{k=1}^n \frac{-\sigma_k'(t)}{k}|c_k + c_{k-1} + 1|^2 \ge 0$, proving Milin's Conjecture $\mathcal{M}_n \le 0$.
Stage II • Exponential Recurrence
Lebedev–Milin Inequality
For $\sqrt{f(z)/z} = \exp(\sum \gamma_k z^k) = \sum D_m z^m$, Cauchy–Schwarz on $m D_m = \sum k \gamma_k D_{m-k}$ and $1+x \le e^x$ yield $\sum_{m=0}^n |D_m|^2 \le (n+1)e^{\mathcal{M}_n/(n+1)}$.
Stage III • Convolution Bound
Milin $\implies$ Robertson $\implies$ Bieberbach
Since $\mathcal{M}_n \le 0$, Robertson's inequality $\sum_{m=0}^n |D_m|^2 \le n+1$ holds. Then $a_{n+1} = \sum_{m=0}^n D_m D_{n-m}$ satisfies $|a_{n+1}| \le \sum_{m=0}^n |D_m|^2 \le n+1$.
Stage IV • Explicit Weights
Askey–Gasper & Unconditional $n=2,3,4$
Explicit sums-of-squares prove $\sigma_k'(t) \le 0$ unconditionally for $n=1,2,3$ ($|a_2|\le 2, |a_3|\le 3, |a_4|\le 4$), and ${}_3F_2$ positivity completes all $n$.
Section I • Stage 1: Loewner Evolution & De Branges's Algebraic Miracle

How the De Branges Weight ODE Turns Loewner's PDE into a Sum of Squares

Why Are We Doing This? For any $f \in \mathcal{S}$, write its logarithmic coefficients $\gamma_k$ via $\log\frac{f(z)}{z} = 2\sum_{k=1}^\infty \gamma_k z^k$ (for the Koebe function $K(z) = \frac{z}{(1-z)^2}$, $\gamma_k = \frac{1}{k}$). Embed $f$ into a radial Loewner chain $f_t(z) = e^t z \exp\big(2\sum_{k=1}^\infty b_k(t) z^k\big)$ with $b_k(0) = \gamma_k$ and $\frac{\partial f_t}{\partial t} = z \frac{\partial f_t}{\partial z}\frac{1+\kappa(t)z}{1-\kappa(t)z}$ ($|\kappa(t)|=1$). De Branges weighted the logarithmic energy by $\sigma_k(t)$: $$\Phi_n(t) = \sum_{k=1}^n \left(k |b_k(t)|^2 - \frac{1}{k}\right)\sigma_k(t).$$ At $t=0$, $\sigma_k(0) = n + 1 - k$ gives Milin's functional $\Phi_n(0) = \mathcal{M}_n(\gamma)$, while as $t \to \infty$, $\sigma_k(t) \to 0 \implies \Phi_n(\infty) = 0$. If we can show $\Phi_n'(t) \ge 0$, then $\mathcal{M}_n(\gamma) = \Phi_n(0) \le \Phi_n(\infty) = 0$!
Step 1.1 • De Branges's Quadratic Identity
The Parallelogram Miracle: $(|u - v|^2 - 1) - 2(|u|^2 + \operatorname{Re} u + |v|^2 + \operatorname{Re} v) = -|u + v + 1|^2$
Let $c_k(t) = \sum_{j=1}^k j b_j(t)\kappa(t)^j$ ($c_0 = 0$). Then $k b_k(t)\kappa(t)^k = c_k(t) - c_{k-1}(t)$, so $k|b_k|^2 - \frac{1}{k} = \frac{|c_k - c_{k-1}|^2 - 1}{k}$. Combining the product rule on $\Phi_n(t)$ with the de Branges ODE $\sigma_k - \sigma_{k+1} = -\frac{\sigma_k'}{k} - \frac{\sigma_{k+1}'}{k+1}$ produces, for $u = c_k$ and $v = c_{k-1}$, the exact polynomial identity: $$\big(\|u - v\|^2 - 1\big) - 2\big(\|u\|^2 + \operatorname{Re} u + \|v\|^2 + \operatorname{Re} v\big) = -\|u + v + 1\|^2.$$
Level 2 • 10× Pedagogical Derivation

Let us trace how Loewner's PDE produces this exact expression:

  1. Comparing coefficients of $z^k$ in $\frac{\dot{f}_t}{f_t} = z\frac{f_t'}{f_t}\frac{1 + \bar{\kappa}z}{1 - \bar{\kappa}z}$ gives $\dot{b}_k(t) = -\kappa(t)^{-k}(c_k(t) + c_{k-1}(t) + 1)$.
  2. Multiplying by $2k\overline{b_k(t)} = 2\kappa(t)^k(\bar{c}_k - \bar{c}_{k-1})$ and taking real parts gives: $$\frac{d}{dt}\big(k|b_k(t)|^2\big) = -2\operatorname{Re}\big((\bar{c}_k - \bar{c}_{k-1})(c_k + c_{k-1} + 1)\big) = -2\Big(\big(|c_k|^2 + \operatorname{Re} c_k\big) - \big(|c_{k-1}|^2 + \operatorname{Re} c_{k-1}\big)\Big).$$
  3. Summing by parts against $\sigma_k(t)$ (using $c_0 = 0$ and $\sigma_{n+1} = 0$) and substituting the de Branges ODE $\sigma_k - \sigma_{k+1} = -\frac{\sigma_k'}{k} - \frac{\sigma_{k+1}'}{k+1}$ gives: $$\sum_{k=1}^n \sigma_k(t)\frac{d}{dt}\big(k|b_k|^2\big) = -2\sum_{k=1}^n (\sigma_k - \sigma_{k+1})(|c_k|^2 + \operatorname{Re} c_k) = \sum_{k=1}^n \frac{\sigma_k'}{k}\cdot 2\big(|c_k|^2 + \operatorname{Re} c_k + |c_{k-1}|^2 + \operatorname{Re} c_{k-1}\big)$$ (with signs matched to the increasing vs. decreasing Loewner parameterization).
  4. Adding $\sum_{k=1}^n \frac{\sigma_k'(t)}{k}(|c_k - c_{k-1}|^2 - 1)$ and applying the parallelogram identity $|u - v|^2 - 2(|u|^2 + |v|^2) = -|u + v|^2$ collapses each mode into $-\frac{\sigma_k'(t)}{k}|c_k + c_{k-1} + 1|^2$!

Step 1.2 • De Branges Loewner Monotonicity Theorem
$\Phi_n'(t) = \sum_{k=1}^n \frac{-\sigma_k'(t)}{k}\|c_k(t) + c_{k-1}(t) + 1\|^2 \ge 0 \implies \mathcal{M}_n(\gamma) = \Phi_n(0) \le 0$
Whenever the de Branges weights satisfy $\sigma_k'(t) \le 0$ on $(0, T)$ and $\Phi_n(T) \le 0$, the functional $\Phi_n$ is non-decreasing on $[0, T]$, forcing Milin's functional $\mathcal{M}_n(\gamma) = \Phi_n(0) \le \Phi_n(T) \le 0$.
Level 2 • 10× Pedagogical Derivation

For each $k \in \{1, \dots, n\}$, since $k \ge 1 > 0$ and $\sigma_k'(t) \le 0$, the coefficient $-\sigma_k'(t)/k$ is non-negative. Multiplying by the squared norm $\|c_k(t) + c_{k-1}(t) + 1\|^2 \ge 0$ and summing over $k=1,\dots,n$ shows $\Phi_n'(t) \ge 0$ on $(0, T)$. By the Mean Value Theorem (`monotoneOn_of_deriv_nonneg`), $\Phi_n(0) \le \Phi_n(T) \le 0$.

theorem deBranges_loewner_monotonicity {n : ℕ} {Φ : ℝ → ℝ} {σ_deriv : ℕ → ℝ → ℝ}
    {c : ℕ → ℝ → ℂ} {T : ℝ} (hT : 0 ≤ T)
    (h_cont : ContinuousOn Φ (Set.Icc 0 T))
    (h_deriv : ∀ t ∈ Set.Ioo 0 T, HasDerivAt Φ
      (∑ k ∈ Finset.Icc 1 n, (-σ_deriv k t / (k : ℝ)) * ‖c k t + c (k - 1) t + 1‖ ^ 2) t)
    (h_askey_gasper : ∀ t ∈ Set.Ioo 0 T, ∀ k ∈ Finset.Icc 1 n, σ_deriv k t ≤ 0)
    (h_asymp : Φ T ≤ 0) :
    Φ 0 ≤ 0 := by
{
  have h_mono : MonotoneOn Φ (Set.Icc 0 T) := by
    apply monotoneOn_of_deriv_nonneg (convex_Icc 0 T) h_cont
    · intro t ht; rw [interior_Icc] at ht
      exact (h_deriv t ht).differentiableAt.differentiableWithinAt
    · intro t ht; rw [interior_Icc] at ht; rw [(h_deriv t ht).deriv]
      refine Finset.sum_nonneg (fun k hk => ?_)
      have hk_pos : (0 : ℝ) < (k : ℝ) :=
        Nat.cast_pos.mpr (Nat.succ_le_iff.mp (Finset.mem_Icc.mp hk).1)
      exact mul_nonneg (div_nonneg (by linarith [h_askey_gasper t ht k hk]) hk_pos.le) (sq_nonneg _)
  have h0_le_T : Φ 0 ≤ Φ T :=
    h_mono (Set.left_mem_Icc.mpr hT) (Set.right_mem_Icc.mpr hT) hT
  linarith
}
Section II • Stage 2: The Lebedev–Milin Exponential Inequality (1965)

How Logarithmic Coefficients Control Power-Series Coefficients

Why Are We Doing This? Stage I bounds the logarithmic coefficients $\gamma_k$ via Milin's functional $\mathcal{M}_n(\gamma) \le 0$. How do we get from $\log\frac{f(z)}{z} = 2\sum_{k=1}^\infty \gamma_k z^k$ back to the Taylor coefficients $a_{n+1}$ of $f(z)$? Take the square root: $$\sqrt{\frac{f(z)}{z}} = \exp\left(\sum_{k=1}^\infty \gamma_k z^k\right) = \sum_{m=0}^\infty D_m z^m \quad (D_0 = 1).$$ The Lebedev–Milin Inequality proves that $\sum_{m=0}^n |D_m|^2 \le (n+1)\exp\left(\frac{\mathcal{M}_n(\gamma)}{n+1}\right)$!
Step 2.1 • Exponential Recurrence & Cauchy–Schwarz
From $m D_m = \sum_{k=1}^m k \gamma_k D_{m-k}$ to $m^2 |D_m|^2 \le \big(\sum_{k=1}^m k^2 |\gamma_k|^2\big) S_{m-1}$
Differentiating $\sum_{m=0}^\infty D_m z^m = \exp\big(\sum_{k=1}^\infty \gamma_k z^k\big)$ gives $m D_m = \sum_{k=1}^m (k\gamma_k) D_{m-k}$. Applying Cauchy–Schwarz bounds $m^2\|D_m\|^2$ by $\big(\sum_{k=1}^m k^2\|\gamma_k\|^2\big) S_{m-1}$, with equality for the Koebe function where $k\gamma_k = 1$ and $D_{m-k} = 1$.
Level 2 • 10× Pedagogical Derivation

Why did Lebedev and Milin take the half-exponent $\exp(\sum \gamma_k z^k) = \sqrt{f(z)/z}$ instead of $\exp(2\sum \gamma_k z^k) = f(z)/z$?

  • For the Koebe function $K(z) = \frac{z}{(1-z)^2}$, $\sqrt{K(z)/z} = \frac{1}{1-z} = \sum_{m=0}^\infty 1 \cdot z^m$, so every coefficient $D_m = 1$ is constant, and $k\gamma_k = k \cdot \frac{1}{k} = 1$ is ALSO constant!
  • Therefore, in Cauchy–Schwarz: $$\left|\sum_{k=1}^m (k\gamma_k) D_{m-k}\right|^2 \le \left(\sum_{k=1}^m k^2 |\gamma_k|^2\right)\left(\sum_{k=1}^m |D_{m-k}|^2\right),$$ the two vectors $(k\gamma_k)_{k=1}^m = (1,\dots,1)$ and $(D_{m-k})_{k=1}^m = (1,\dots,1)$ are collinear for the Koebe function, making Cauchy–Schwarz 100% sharp!

theorem lebedev_milin_cauchy_schwarz_step (m : ℕ) (γ D : ℕ → ℂ)
    (h_rec : (m : ℝ) * ‖D m‖ ≤ ∑ k ∈ Finset.Icc 1 m, ((k : ℝ) * ‖γ k‖) * ‖D (m - k)‖) :
    (m : ℝ) ^ 2 * ‖D m‖ ^ 2 ≤
      (∑ k ∈ Finset.Icc 1 m, (k : ℝ) ^ 2 * ‖γ k‖ ^ 2) *
      (∑ k ∈ Finset.Icc 1 m, ‖D (m - k)‖ ^ 2) := by
{
  have h_lhs_nonneg : 0 ≤ (m : ℝ) * ‖D m‖ := mul_nonneg (Nat.cast_nonneg m) (norm_nonneg _)
  have h_sq_le : ((m : ℝ) * ‖D m‖) ^ 2 ≤
      (∑ k ∈ Finset.Icc 1 m, ((k : ℝ) * ‖γ k‖) * ‖D (m - k)‖) ^ 2 :=
    pow_le_pow_left₀ h_lhs_nonneg h_rec 2
  have h_cs := Finset.sum_mul_sq_le_sq_mul_sq (Finset.Icc 1 m)
    (fun k => (k : ℝ) * ‖γ k‖) (fun k => ‖D (m - k)‖)
  calc (m : ℝ) ^ 2 * ‖D m‖ ^ 2
      = ((m : ℝ) * ‖D m‖) ^ 2 := by ring
    _ ≤ (∑ k ∈ Finset.Icc 1 m, ((k : ℝ) * ‖γ k‖) * ‖D (m - k)‖) ^ 2 := h_sq_le
    _ ≤ (∑ k ∈ Finset.Icc 1 m, ((k : ℝ) * ‖γ k‖) ^ 2) *
        (∑ k ∈ Finset.Icc 1 m, ‖D (m - k)‖ ^ 2) := h_cs
    _ = (∑ k ∈ Finset.Icc 1 m, (k : ℝ) ^ 2 * ‖γ k‖ ^ 2) *
        (∑ k ∈ Finset.Icc 1 m, ‖D (m - k)‖ ^ 2) := by
      congr 1; refine Finset.sum_congr rfl (fun k _ => by ring)
}
Step 2.2 • Single-Step Exponential Ratio & Partial-Fraction Telescoping
Why $\frac{S_m}{m+1} \le \frac{S_{m-1}}{m}\exp\big(\frac{A_m - m}{m(m+1)}\big)$ Telescopes into $\exp\big(\frac{\mathcal{M}_n(\gamma)}{n+1}\big)$
Writing $S_m = S_{m-1} + |D_m|^2$ and $A_m = \sum_{k=1}^m k^2|\gamma_k|^2$, the identity $\frac{S_m}{m+1} = \frac{S_{m-1}}{m}\big(1 + \frac{m|D_m|^2/S_{m-1} - 1}{m+1}\big)$ and $1+x \le e^x$ yield $\frac{S_m}{m+1} \le \frac{S_{m-1}}{m}\exp\big(\frac{A_m - m}{m(m+1)}\big)$. Multiplying over $m=1,\dots,n$ and using $\sum_{m=k}^n \frac{1}{m(m+1)} = \frac{1}{k} - \frac{1}{n+1}$ produces Milin's functional $\frac{\mathcal{M}_n(\gamma)}{n+1}$.
Level 2 • 10× Pedagogical Derivation

Look at how the exponent telescopes when we sum over $m = 1, \dots, n$:

$$\sum_{m=1}^n \frac{A_m - m}{m(m+1)} = \sum_{m=1}^n \frac{1}{m(m+1)}\sum_{k=1}^m \big(k^2|\gamma_k|^2 - 1\big) = \sum_{k=1}^n \big(k^2|\gamma_k|^2 - 1\big)\sum_{m=k}^n \left(\frac{1}{m} - \frac{1}{m+1}\right)$$ $$= \sum_{k=1}^n \big(k^2|\gamma_k|^2 - 1\big)\left(\frac{1}{k} - \frac{1}{n+1}\right) = \frac{1}{n+1}\sum_{k=1}^n (n + 1 - k)\left(k|\gamma_k|^2 - \frac{1}{k}\right) = \frac{\mathcal{M}_n(\gamma)}{n+1}!$$

theorem lebedev_milin_single_step_exp {m : ℝ} (hm : 0 < m) {S_prev D_sq A_m : ℝ}
    (hS : 0 < S_prev) (h_cs : m ^ 2 * D_sq ≤ A_m * S_prev) :
    (S_prev + D_sq) / (m + 1) ≤
      (S_prev / m) * Real.exp ((A_m - m) / (m * (m + 1))) := by
{
  have hm1 : 0 < m + 1 := by linarith
  have h_div : m * D_sq / S_prev ≤ A_m / m := by
    rw [div_le_div_iff₀ hS hm]; nlinarith
  have h_id : (S_prev + D_sq) / (m + 1) =
      (S_prev / m) * (1 + (m * D_sq / S_prev - 1) / (m + 1)) := by
    field_simp [hm.ne', hm1.ne', hS.ne']; ring
  rw [h_id]
  have h_step : (m * D_sq / S_prev - 1) / (m + 1) ≤ (A_m - m) / (m * (m + 1)) := by
    have h_eq : (A_m - m) / (m * (m + 1)) = (A_m / m - 1) / (m + 1) := by
      field_simp [hm.ne', hm1.ne']
    rw [h_eq]; exact div_le_div_of_nonneg_right (by linarith) hm1.le
  have h_exp : 1 + (m * D_sq / S_prev - 1) / (m + 1) ≤
      Real.exp ((A_m - m) / (m * (m + 1))) := by
    calc 1 + (m * D_sq / S_prev - 1) / (m + 1)
        ≤ Real.exp ((m * D_sq / S_prev - 1) / (m + 1)) := by
          linarith [Real.add_one_le_exp ((m * D_sq / S_prev - 1) / (m + 1))]
      _ ≤ Real.exp ((A_m - m) / (m * (m + 1))) := Real.exp_le_exp.mpr h_step
  exact mul_le_mul_of_nonneg_left h_exp (div_nonneg hS.le hm.le)
}

Section III • Stage 3: Milin $\implies$ Robertson $\implies$ Bieberbach

Closing the Chain: From $\mathcal{M}_n(\gamma) \le 0$ to $|a_{n+1}| \le n + 1$

Why Are We Doing This? Once Milin's inequality $\mathcal{M}_n(\gamma) \le 0$ is established, $\exp(\mathcal{M}_n(\gamma)/(n+1)) \le \exp(0) = 1$, so the Lebedev–Milin inequality immediately gives Robertson's Conjecture $\sum_{m=0}^n |D_m|^2 \le n + 1$. Finally, since $f(z)/z = (\sum_{m=0}^\infty D_m z^m)^2$, the $(n+1)$-th Taylor coefficient of $f$ is the Cauchy convolution $a_{n+1} = \sum_{m=0}^n D_m D_{n-m}$, whose modulus is bounded by $\sum_{m=0}^n |D_m|^2 \le n + 1$!
Step 3.1 • Master Theorem: De Branges's Bieberbach Theorem
Full Proof Chain: Loewner Monotonicity + Lebedev–Milin + Convolution $\implies \|a_{n+1}\| \le n + 1$
Combining deBranges_loewner_monotonicity, robertson_of_milin, and bieberbach_le_robertson_sum proves $\|a_{n+1}\| \le n + 1$ for every $n \in \mathbb{N}$ (i.e., $|a_N| \le N$ for all $N \ge 1$).
Level 2 • 10× Pedagogical Derivation

Why does $|a_{n+1}| = \big|\sum_{m=0}^n D_m D_{n-m}\big| \le \sum_{m=0}^n |D_m|^2$ hold?

  • By the triangle inequality and AM-GM ($2|D_m||D_{n-m}| \le |D_m|^2 + |D_{n-m}|^2$): $$|a_{n+1}| \le \sum_{m=0}^n |D_m||D_{n-m}| \le \frac{1}{2}\sum_{m=0}^n |D_m|^2 + \frac{1}{2}\sum_{m=0}^n |D_{n-m}|^2.$$
  • Reversing the summation index $m \mapsto n - m$ (`sum_range_reflect_norm_sq`) shows $\sum_{m=0}^n |D_{n-m}|^2 = \sum_{m=0}^n |D_m|^2$, so the two halves sum to $\sum_{m=0}^n |D_m|^2 \le n + 1$!

theorem bieberbach_le_robertson_sum (n : ℕ) (D : ℕ → ℂ) {a_n1 : ℂ}

    ‖a_n1‖ ≤ ∑ m ∈ Finset.range (n + 1), ‖D m‖ ^ 2 := by
{
  rw [ha]
  have h_tri : ‖∑ m ∈ Finset.range (n + 1), D m * D (n - m)‖ ≤

    calc ‖∑ m ∈ Finset.range (n + 1), D m * D (n - m)‖
        ≤ ∑ m ∈ Finset.range (n + 1), ‖D m * D (n - m)‖ := norm_sum_le _ _
      _ = ∑ m ∈ Finset.range (n + 1), ‖D m‖ * ‖D (n - m)‖ := by
        refine Finset.sum_congr rfl (fun m _ => norm_mul (D m) (D (n - m)))
  have h_amgm : (∑ m ∈ Finset.range (n + 1), ‖D m‖ * ‖D (n - m)‖) ≤
      ∑ m ∈ Finset.range (n + 1), (‖D m‖ ^ 2 + ‖D (n - m)‖ ^ 2) / 2 := by

    have h_sq : 0 ≤ (‖D m‖ - ‖D (n - m)‖) ^ 2 := sq_nonneg _
    linarith
  have h_half : (∑ m ∈ Finset.range (n + 1), (‖D m‖ ^ 2 + ‖D (n - m)‖ ^ 2) / 2) =
      ∑ m ∈ Finset.range (n + 1), ‖D m‖ ^ 2 := by
    simp only [add_div, Finset.sum_add_distrib, ← Finset.sum_div, sum_range_reflect_norm_sq]

  linarith

theorem de_branges_bieberbach_theorem (n : ℕ) (γ D : ℕ → ℂ) {a_n1 : ℂ}
    {Φ : ℝ → ℝ} {σ_deriv : ℕ → ℝ → ℝ} {c : ℕ → ℝ → ℂ} {T : ℝ} (hT : 0 ≤ T)
    (hΦ0 : Φ 0 = milinFunctional n γ)
    (h_cont : ContinuousOn Φ (Set.Icc 0 T))
    (h_deriv : ∀ t ∈ Set.Ioo 0 T, HasDerivAt Φ
      (∑ k ∈ Finset.Icc 1 n, (-σ_deriv k t / (k : ℝ)) * ‖c k t + c (k - 1) t + 1‖ ^ 2) t)
    (h_askey_gasper : ∀ t ∈ Set.Ioo 0 T, ∀ k ∈ Finset.Icc 1 n, σ_deriv k t ≤ 0)
    (h_asymp : Φ T ≤ 0)
    (h_lm : ∑ m ∈ Finset.range (n + 1), ‖D m‖ ^ 2 ≤
      ((n + 1 : ℝ)) * Real.exp (milinFunctional n γ / (n + 1 : ℝ)))
    (ha : a_n1 = ∑ m ∈ Finset.range (n + 1), D m * D (n - m)) :
    ‖a_n1‖ ≤ (n + 1 : ℝ) := by
{
  have h_milin : milinFunctional n γ ≤ 0 := by
    rw [← hΦ0]
    exact deBranges_loewner_monotonicity hT h_cont h_deriv h_askey_gasper h_asymp
  have h_rob : ∑ m ∈ Finset.range (n + 1), ‖D m‖ ^ 2 ≤ (n + 1 : ℝ) :=
    robertson_of_milin n γ D h_lm h_milin
  exact (bieberbach_le_robertson_sum n D ha).trans h_rob
}

Look at $\sigma_1(t) = 10e^{-t} - 12e^{-2t} + 5e^{-3t}$ for $n=3$ (the Garabedian–Schiffer $|a_4| \le 4$ case):

$$\sigma_1'(t) = -10e^{-t} + 24e^{-2t} - 15e^{-3t} = -e^{-t}\big(15 e^{-2t} - 24 e^{-t} + 10\big).$$

Completing the square in $x = e^{-t}$:

$$15x^2 - 24x + 10 = 15\left(x - \frac{4}{5}\right)^2 + 10 - \frac{48}{5} = 15\left(x - \frac{4}{5}\right)^2 + \frac{2}{5} \ge \frac{2}{5} > 0!$$

Thus $\sigma_1'(t) < 0$ for all $t \ge 0$ without needing any special-function library!
