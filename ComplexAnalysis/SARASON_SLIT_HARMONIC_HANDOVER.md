2. **The Poisson Kernel on the Unit Disk $\mathbb{D}$:**
   - Define the Herglotz kernel and Poisson kernel for $z = r e^{i\theta} \in \mathbb{D}$ and $e^{it} \in \partial\mathbb{D}$:
     $$H(z, e^{it}) = \frac{e^{it} + z}{e^{it} - z}, \qquad P(z, e^{it}) = \text{Re}\left(\frac{e^{it} + z}{e^{it} - z}\right) = \frac{1 - |z|^2}{|e^{it} - z|^2}.$$
   - Prove that $z \mapsto P(z, e^{it})$ is harmonic and strictly positive on $\mathbb{D}$, with $P(0, e^{it}) = 1$.
3. **Harmonic Measure on $\mathbb{D}$ via the Poisson Integral:**
   - For any boundary arc $I = \{e^{it} : \varphi_1 < t < \varphi_2\} \subset \partial\mathbb{D}$, define its harmonic measure in $\mathbb{D}$ at $z \in \mathbb{D}$ as the Poisson integral of $\mathbf{1}_I$:
     $$\omega(z; I; \mathbb{D}) := \frac{1}{2\pi} \int_{\varphi_1}^{\varphi_2} \text{Re}\left(\frac{e^{it} + z}{e^{it} - z}\right) dt.$$
   - Prove the **Mean-Value / Origin Identity**:
     $$\omega(0; I; \mathbb{D}) = \frac{\varphi_2 - \varphi_1}{2\pi}.$$

### Phase 3: Starlike Univalent Maps & Pommerenke's Slit Formula (Sarason Ch. X + Pommerenke Thm. 3.18)
1. **Conformal Invariance of Harmonic Measure:**
   - Given a univalent holomorphic map $f : \mathbb{D} \to \Omega$ with $f(0) = 0$, define the harmonic measure $\omega(0; E; \Omega)$ of a prime-end / boundary slit $E = f(I)$ ($I = (e^{i\varphi_k}, e^{i\varphi_{k+1}}) \subset \partial\mathbb{D}$) by conformal pullback $\omega(0; I; \mathbb{D}) = \frac{\varphi_{k+1} - \varphi_k}{2\pi}$.
2. **Analytic Starlike Criterion ($\text{Re}(z f'(z) / f(z)) > 0$):**
   - Formalize the logarithmic derivative identity for the Pommerenke product map:
     $$f(z) = z \prod_{j=1}^{2n} (1 - \bar{z}_j z)^{-\sigma_j} \implies \frac{z f'(z)}{f(z)} = 1 + \sum_{j=1}^{2n} \frac{\sigma_j \bar{z}_j z}{1 - \bar{z}_j z} = \sum_{j=1}^{2n} \frac{\sigma_j}{2} \frac{z_j + z}{z_j - z}$$
     whenever $\sum_{j=1}^{2n} \sigma_j = 2$ and $|z_j| = 1$.
   - Because each Herglotz factor $\frac{z_j + z}{z_j - z}$ has strictly positive real part on $\mathbb{D}$ (`P(z, z_j) > 0`) and purely imaginary values on $\partial\mathbb{D} \setminus \{z_j\}$, any convex combination with $\sigma_j > 0, \sum \sigma_j = 2$ satisfies:
     1. $\text{Re}\left(\frac{z f'(z)}{f(z)}\right) > 0$ for all $z \in \mathbb{D}$ (proving $f(\mathbb{D})$ is starlike with respect to $0$!),
     2. $\text{Re}\left(\frac{e^{it} f'(e^{it})}{f(e^{it})}\right) = 0$ on each open boundary arc $e^{it} \in (z_k, z_{k+1}) \subset \partial\mathbb{D}$ (proving $\frac{d}{dt} \arg f(e^{it}) = 0$, so each arc $(z_k, z_{k+1})$ maps onto a radial slit $R_k$ of constant argument $\theta_k$!),
     3. $\frac{d}{dt} \log |f(e^{it})| = -\text{Im}\left(\frac{e^{it} f'(e^{it})}{f(e^{it})}\right)$ changes sign at a unique critical point $t_k \in (\varphi_k, \varphi_{k+1})$ (the slit tip $\rho_k e^{i\theta_k} = f(e^{i t_k})$),
     4. Near $z_k = e^{i\varphi_k}$, the argument jumps by $\Delta\theta_k = \sigma_k \pi$ (proving $\sigma_k \pi$ is the exact asymptotic angular gapwidth of channel $k$!).
